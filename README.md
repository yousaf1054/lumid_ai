# Lumid AI - Mental Wellness Companion

Lumid AI is a responsive mental wellness companion application built with React and Tailwind CSS. It features a comforting interface with a mood tracker and chat capabilities to support emotional well-being.

## Features

-   **Interactive Chat Interface**: A clean, distraction-free chat area.
-   **Mood Tracker**: Visual mood tracking with emoji indicators and tag selection for specific feelings.
-   **Responsive Design**: Optimized for mobile, tablet, and desktop views.
-   **Comforting Aesthetics**: Designed with calming colors and a friendly mascot.

## Tech Stack

-   **Frontend**: React (Vite)
-   **Styling**: Tailwind CSS
-   **Icons**: Lucide React

## Getting Started

### Prerequisites

Ensure you have Node.js installed.

### Installation

1.  Clone the repository:
    ```bash
    git clone https://github.com/yousaf1054/lumid_ai.git
    cd lumid_ai
    ```

2.  Install dependencies:
    ```bash
    npm install
    ```

3.  Start the development server:
    ```bash
    npm run dev
    ```

## Project Structure

-   `src/components`: Reusable UI components (Header, ChatInput, MoodTracker, etc.)
-   `resources/`: Static assets (images, icons)
-   `src/App.jsx`: Main application layout
